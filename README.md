# 🏆 GitHub Achievements

GitHub Achievements celebrate specific events and actions performed on GitHub. They appear in the **Achievements** section of eligible user profiles.

GitHub launched the expanded Achievements experience in **June 2022**. Some achievements support multiple tiers, while others have only a single level.

## 🫛 Pair Extraordinaire

<p align="center">
  <img src="https://github.githubassets.com/assets/pair-extraordinaire-default-579438a20e01.png" width="170" alt="Pair Extraordinaire">
</p>

**Status:** ✅ Available  
**Type:** GitHub Achievement  
**Introduced:** June 2022  
**Tiered:** Yes

### How to Earn

Coauthor commits that are included in successfully merged pull requests.

GitHub supports adding multiple authors to a commit using a `Co-authored-by:` trailer. Qualifying coauthored work must ultimately be included in a merged pull request.

### Levels

| Level | Label | Requirement |
|---|:---:|---:|
| Default | — | Qualifying coauthored merged pull request |
| Bronze | `x2` | 10 coauthored merged pull requests |
| Silver | `x3` | 24 coauthored merged pull requests |
| Gold | `x4` | 48 coauthored merged pull requests |

<p align="center">

</p>

**Status:** ✅ Available  
**Type:** GitHub Achievement  
**Introduced:** June 2022  
**Tiered:** Yes

### How to Earn

Create a repository that receives enough GitHub stars.

### Levels

| Level | Label | Repository Stars |
|---|:---:|---:|
| Default | — | 16 |
| Bronze | `x2` | 128 |
| Silver | `x3` | 512 |

## 🧠 Galaxy Brain

<p align="center">
  <img src="https://github.githubassets.com/assets/galaxy-brain-default-847262c21056.png" width="170" alt="Galaxy Brain">
</p>

**Status:** ✅ Available  
**Type:** GitHub Achievement  
**Introduced:** June 2022  
**Tiered:** Yes

### How to Earn

Provide useful answers in a repository's **GitHub Discussions** and have those responses marked as accepted answers.

### Levels

| Level | Label | Accepted Answers |
|---|:---:|---:|
| Default | — | 2 |
| Bronze | `x2` | 8 |
| Silver | `x3` | 16 |
| Gold | `x4` | 32 |

> [!WARNING]
> GitHub disabled earning Achievements inside the official **GitHub Community Discussions** in February 2024 because of coordinated and low-quality activity intended only to farm achievements.
>
> This does **not** mean Galaxy Brain itself was removed. Qualifying Discussions in other repositories can still count.

# 🪦 Retired Achievements

These achievements remain visible on profiles that earned them, but their qualifying events have ended.

## 🧊 Arctic Code Vault Contributor

<p align="center">
  <img src="https://github.githubassets.com/assets/arctic-code-vault-contributor-default-df8d74122a06.png" width="170" alt="Arctic Code Vault Contributor">
</p>

**Status:** ❌ Retired  
**Type:** Historical GitHub Achievement  
**Introduced:** April 2021  
**Tiered:** No

### How It Was Earned

Contribute code to a qualifying repository that was included in the **2020 GitHub Archive Program**.

GitHub preserved a snapshot of public open-source repositories in the Arctic World Archive. Contributors to qualifying repositories received this badge on their profiles.

> [!IMPORTANT]
> The archive event has ended. This achievement can no longer be newly earned.

## 🚁 Mars 2020 Contributor

<p align="center">
  <img src="https://github.githubassets.com/assets/mars-2020-contributor-default-c9cad8495acf.png" width="170" alt="Mars 2020 Contributor">
</p>

**Status:** ❌ Retired  
**Type:** Historical GitHub Achievement  
**Originally introduced:** April 2021  
**Renamed / redesigned:** June 2022  
**Tiered:** No

### How It Was Earned

Author a commit in one of the qualifying open-source repositories and versions used by NASA/JPL for the **Mars 2020 Ingenuity Helicopter mission**.

GitHub's documentation maintains the historical list of qualifying repositories, versions, and tags.

### Historical Name

The original badge was named **Mars 2020 Helicopter Contributor**.

> [!IMPORTANT]
> GitHub explicitly states that this event has ended and the badge is no longer available.

# 🎖️ Profile & Program Badges

GitHub distinguishes **program/profile badges** from **Achievements**. GitHub's current profile documentation lists five program badges that can automatically appear on a user's profile.

## Developer Program Member

**Status:** ✅ Available  
**Type:** Profile / program badge

### How to Get It

Register for the **GitHub Developer Program** and participate as a developer building with GitHub's API/platform.

---

## PRO

**Status:** ✅ Available  
**Type:** Account-plan badge

### How to Get It

Use the **GitHub Pro** plan.

---

## Security Bug Bounty Hunter

**Status:** ✅ Available  
**Type:** Security program badge

### How to Get It

Help GitHub identify qualifying security vulnerabilities through GitHub's security/bug-bounty program.

---

## GitHub Campus Expert

**Status:** ✅ Available  
**Type:** Education program badge

### How to Get It

Successfully participate in the **GitHub Campus Experts** program.

---

## Security Advisory Credit

**Status:** ✅ Available  
**Type:** Security/profile badge

### How to Get It

Submit a security advisory that is accepted into the **GitHub Advisory Database**.

---

## GitHub Star

**Status:** ✅ Program active  
**Type:** GitHub Stars program / profile recognition

GitHub Stars recognizes community leaders who inspire, educate, and build communities around open source and GitHub.

> [!NOTE]
> GitHub's current general profile-reference badge table does not enumerate every possible special-program recognition. GitHub Star is kept separate here for completeness rather than being counted as one of the five standard profile badges listed in that table.

# 🏢 Organization Badges

## Verified

**Status:** ✅ Available  
**Type:** Organization profile badge

GitHub organizations can display a **Verified** badge after GitHub verifies ownership of the organization's domain.

### General Requirements

The organization's displayed website/email information must match its verified domain configuration. Domain ownership is verified through GitHub's organization settings and DNS verification process.

> [!NOTE]
> This is an organization badge, not a personal-profile Achievement.

# 🛒 GitHub Marketplace Badges

GitHub Marketplace uses verification/listing badges for qualifying app listings.

## Publisher Domain and Email Verified

**Status:** ✅ Available  
**Type:** GitHub Marketplace badge

The tooltip reads:

> **Publisher domain and email verified**

It indicates that the publisher organization has completed GitHub's publisher-verification requirements, including domain verification, a confirmed contact email, and required two-factor authentication for the organization.

---

## App Meets the Requirements for Listing

**Status:** ✅ Available  
**Type:** GitHub Marketplace listing badge

The tooltip reads:

> **App meets the requirements for listing**

This means the app meets Marketplace listing requirements, but the publisher has not completed publisher verification.

> [!IMPORTANT]
> A GitHub Marketplace badge is not an endorsement or security review of third-party code.

# 🚦 GitHub Actions Workflow Status Badges

**Status:** ℹ️ Generated dynamically  
**Type:** Repository / README status badge

GitHub Actions can generate status badges showing whether a workflow is currently **passing** or **failing**.

These badges can represent:

- The repository's default branch
- A specific branch
- A specific event
- A specific workflow

### Example

```md
![Workflow Status](https://github.com/OWNER/REPOSITORY/actions/workflows/WORKFLOW.yml/badge.svg)
```

> [!NOTE]
> Workflow badges are not collectible profile Achievements. They are included because they are official GitHub-native badges commonly displayed in repositories.

# ❓ Frequently Asked Questions

## Can retired achievements still be earned?

No. The **Arctic Code Vault Contributor** and **Mars 2020 Contributor** events have ended.

## Can I still earn Galaxy Brain?

Yes, through qualifying accepted answers in repository GitHub Discussions. However, GitHub disabled earning Achievements specifically within GitHub's own Community Discussions in 2024 because of achievement-farming abuse.

## Why don't I see Achievements on a profile?

GitHub allows users to hide individual Achievements or disable the Achievements section entirely.

## Are Heart On Your Sleeve and Open Sourcerer real?

They were genuine achievement designs exposed/tested by GitHub, but they are currently disabled and should not be treated as publicly earnable Achievements.

## Can I earn the Proxima achievements?

Not through normal public GitHub activity. They are internal GitHub staff achievements.

## Are GitHub program badges the same as Achievements?

No. GitHub documents program/profile badges separately from the Achievements system.

# 🖼️ Image Policy

The goal of this repository is to preserve **real GitHub badge artwork**, not recreations or AI-generated substitutes.

For the final self-hosted version:

```text
assets/
├── achievements/
├── retired/
├── experimental/
├── internal/
├── profile-badges/
├── organization/
├── marketplace/
├── legacy/
└── workflow-status/
```

Each externally referenced image in this initial README should eventually be copied into its matching `assets/` folder and the README updated to use the local path.

Example:

```md
<img src="assets/achievements/pull-shark/default.png" width="170" alt="Pull Shark">
```

This prevents the project from relying permanently on third-party hotlinks.
